Накладные светильники: что важно знать

Накладные светильники выручают там, где нет запотолочного пространства: бетонные перекрытия, лофты, реконструкция. Цилиндры серий M15, M1810, M1015 дают акцентный или общий свет с Ra > 90 и выбором угла 15° / 30° / 45°. Панели SOFI толщиной 25–35 мм закрывают задачу общего освещения помещений с DIP-переключателем температуры 3000 / 4000 / 6500 K.

Для влажных зон и уличных навесов подойдут модели с защитой IP54–IP65: VEVO, EMO, SOFI X7 IP54.
